## 🎯 Profile Picture & Bio

### Add Profile Picture
1. Go to https://github.com/settings/profile
2. Upload your picture (recommended: 400x400px, professional photo)

### Update Bio
1. Profile Settings
2. Add short bio (160 characters max)
3. Example: "Frontend Developer | React & Next.js | Building beautiful web experiences"

---

## 📌 Pinned Repositories

To pin repositories:
1. Go to your profile
2. Click on a repository
3. Click the pin icon (in the top-right area)
4. Can pin up to 6 repositories

**Tips:**
- Pin your 3-6 best projects
- Keep them updated
- Add quality README files
- Regular commits/activity

---

## ✏️ File Location & Setup

1. Create new repository named **[USERNAME]**
   - Example: If username is "john", create repo "john"
   
2. Add README.md file
   - This will show on your profile

3. Repository must be PUBLIC

4. The README content will display on your GitHub profile

## ⚡ Pro Tips

1. **Keep it Fresh** - Update every 3-6 months
2. **Use Consistent Styling** - Keep badges/colors consistent
3. **Quality Over Quantity** - 3 great projects > 10 mediocre ones
4. **Tell Your Story** - Make it personal and authentic
5. **Include Metrics** - Show impact with numbers
6. **Call-to-Action** - Clear way to contact you
7. **Test Everything** - Links, images, layout on mobile
8. **Regular Updates** - Show activity and growth
